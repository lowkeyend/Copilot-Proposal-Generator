Branded `.docx` templates and reusable section snippets can be placed here.

If you want export to start from a corporate Word file instead of generating
layout from scratch, place the master template here as:

`master_proposal_template.docx`

Supported placeholder tokens inside the template:

- `{{PROPOSAL_TITLE}}`
- `{{CLIENT_NAME}}`
- `{{INDUSTRY}}`
- `{{PROJECT_TYPE}}`
- `{{DATE}}`
- `{{TOC}}`
- `{{SECTIONS}}`
- `{{SECTION:Exact Section Title}}`
